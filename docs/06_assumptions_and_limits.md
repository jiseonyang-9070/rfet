# 06. 가정 전체 목록, 각각의 영향, 미해결 항목

"만들 때는 항상 이유가 있어야 한다"는 원칙에 따라, 이 모델에 들어간 모든 가정을 한 곳에 모은다. 각 가정에 대해 (i) 왜 필요했나, (ii) 결과에 어떤 방향으로 영향을 주나, (iii) 어떻게 확인했거나 확인할 수 있나를 적는다.

## 6-1. 기하 가정

| # | 가정 | 왜 | 영향 방향 | 확인 상태 |
|---|---|---|---|---|
| G1 | 2D 단면 (폭 방향 균일) | 3D 는 비용·정보 부족 | 폭 가장자리 fringe 누락. 폭 ≫ 두께이면 작음 | 미확인 (폭 수치 논문에 없음) |

## 6-5. DEVSIM 의 한계 (솔직하게)

- 영역별 **스칼라** ε 만 기본 지원. 텐서는 사용자 edge 모델을 짜야 하고, 이번에는 독립 FEM 으로 대신 정량화했다.
- 내장 `add_2d_contact` 가 gmsh 경로 mesh 에서 접점을 못 잡는 경우가 있어, 평행판 검증도 gmsh 경로로 우회했다.
- 2D 는 "단위 깊이" 모델이므로 폭 효과 없음.
- Windows 에서 MKL 별도 설치 필요.
- 접점의 Schottky 조건은 Dirichlet ψ 로만 넣었다(평형이므로 충분). 전류 단계에서는 열전자/터널링 경계 flux 모델을 직접 짜야 한다 (DEVSIM 에 내장 Schottky 전류 모델 없음).
