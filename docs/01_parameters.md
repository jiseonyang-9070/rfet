# 01. STEP 1 — 파라미터: 값, 출처, 결정 근거, 검증 상태

이 문서는 모델에 들어간 **모든 숫자**에 대해 네 가지를 답한다.
1. 값이 얼마인가
2. 어디서 왔는가 (분류와 출처)
3. 왜 그 값을 택했는가
4. **원문에서 직접 확인했는가** (2026-11-09 기준)
